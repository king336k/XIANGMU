# 一次性接入适配

1. 原DAQ业务仍走数据平台可信身份Bridge，保留数据平台token、服务端签名和幂等规则；无需在DAQ网页添加“启动frp”操作。
2. 内网同机或分机：按现有独立环境配置填写数据平台与项目平台服务地址，不启用frp。
3. 仅DAQ联网：数据平台的独立Bridge上游配置为指定DAQ网关私网18000地址；项目平台来源连接为云端私网访客6324地址。不要覆盖另一个环境的原配置。
4. 采集电脑端frpc和Nginx固定路径代理由部署管理员安排后台常驻，业务人员仍正常登录DAQ和上报。公网端另部署frps与cloud角色。
5. `check_issue_network.py`仅做只读TCP预检，支持三个地址，既不改系统配置，也不发送凭据或声称业务鉴权成功。
6. `data-platform.env.example`没有实际凭据；生产签名密钥继续从现有密钥管理注入。

正式启用前在目标电脑检查端口、TLS和业务权限；当前包只在独立容器中验收，没有自动安装到电脑或服务器。
