# 混合并发下的终端查询优化

四路真实模型修复、三路终端、三路文件传输同时运行时，终端 HTTP 往返 P95 约为1.6–1.8秒。终端轮询每次重复同步管理员的全局成员关系，刷新会话后又丢弃刚读取的设备关联；采集心跳还多次校验同一设备所有者。

终端 HTTP 传输改为和 WebSocket 相同的专用授权路径，继续逐请求检查当前登录、所有者、设备、项目成员、目标版本及过期状态，不触发无关的全局成员关系投影。设备数据在取得行锁后读取；同一次心跳内复用同一用户的权限判断，下一请求重新验证，不建立跨请求权限缓存。

单次终端读取查询数从25降至14，低负载中位耗时约16.9ms降至9.5ms。权限撤销不会被自动成员投影重新恢复，其他终端所有者仍单独检查。

## 配对验证

同一隔离环境、10个用户和采集进程，四路真实配置模型完整任务，三路终端、三路文件，约124秒混合负载；资源上限保持相同。

| 指标            | 原版本               | 优化后               |
| --------------- | -------------------- | -------------------- |
| 三路终端往返P95 | 1794 / 1618 / 1677ms | 1387 / 1344 / 1421ms |
| HTTP P95        | 561ms                | 487ms                |
| 完整修复并复测  | 4/4                  | 4/4                  |
| 终端有效往返    | 238                  | 295                  |
| 上传下载校验    | 36组                 | 39组                 |
| 非预期HTTP错误  | 0                    | 0                    |
| 同机互斥预期409 | 8次                  | 8次                  |

三路终端P95的平均值约改善18%。另一轮优化测试为1312–1344ms，四路修复同样通过。新增查询预算与权限测试先失败后通过，终端/站点WebSocket、队列、文件互斥和接入回归通过。

这是隔离中央HTTP与真实执行进程的测试，使用平台配置的真实模型；不是10台实物电脑，也不是公网浏览器WebSocket延迟承诺。压力下终端仍有约1.3–1.4秒等待，不能称为本地SSH流畅度。未改DAQ、运行镜像或数据库结构，未操作机器人。
