# 电脑身份与执行进程生命周期

电脑持久卡片与短期执行进程分开。采集端每次进程启动产生新的 `terminal.executor_instance`，正常心跳及DAQ采集员变化保持该值。系统boot、IP、DAQ版本与登录采集员都不能被当作新电脑登记依据。

平台发现执行进程变化时，保留工作站、历史反馈及接入凭据，关闭旧终端、使旧任务失败并清空未执行命令。这样执行端单独重启后，两个遗留终端不会持续占满会话名额，旧命令也不会在新进程上继续执行。相同进程心跳不打断会话；旧客户端缺少该字段时沿用原行为。

相关回归覆盖双终端清理、原卡片保留、同进程不误关闭、旧客户端兼容、旧任务和待执行命令中止。DAQ首次依赖安装和日常启动的幂等性在DAQ仓库单独验证，模型无需获得额外系统权限。
