# 独立账号与DAQ反馈

项目管理平台独立维护登录账号、项目、任务和业务岗位。已移除数据平台登录、账号互认、来源目录、项目任务同步与外部数据回归入口；保留历史业务记录。已有外部会话退出后使用本地独立账号。空库首次部署初始化管理员，重复部署不重置已有管理员密码。

合并DAQ的原登录流程保持不变。采集员继续用原有账号登录DAQ；Web设备会话只保留用户编号和用户名用于反馈签名。项目平台把用户名作为上报人展示，不创建采集员登录账号、项目成员、身份映射或来源项目关系。专用设备签名不能登录平台或调用普通项目API；签名覆盖方法、路径、正文摘要、时间和单次随机数。

设置中的“DAQ 项目授权”按项目勾选，所有采集电脑共用清单，无需分配工作区。查询在服务端搜索和分页，搜索/翻页保留未保存勾选，保存检查版本冲突，撤销授权后不能再反馈或访问该项目反馈。项目三点菜单中的“项目菜单设置”按项目统一隐藏导航，至少保留一项，不改变数据和权限。

DAQ反馈标题只保留现场描述首行；范围、阶段、模块、类型位于概况。历史堆叠标题按展示投影整理，签名原始记录保持不变。
