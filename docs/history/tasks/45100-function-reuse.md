## 用户实际入口

不按接口数建菜单。使用者主要在项目/工作项、缺陷、测试、知识与AI、成员与集成中完成工作。

测试：测试执行（计划与历史）→用例与套件（可选复用）→结果与发布（报告后按需检查）。缺陷：先读现象和证据→分派/方案/修复→回归→经理确认；高级来源元信息默认收起。
