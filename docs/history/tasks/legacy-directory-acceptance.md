## 已实现

`GET quality/integrations/legacy-directory/?source_instance=...` 仅实例管理员且具备项目访问时可读。

连接的 `directory_auth` 可为 `bearer` 或 `trusted_v2`。V2配置只保存非密钥引用：`directory_key_id`、`directory_user_id`、`directory_username`。

服务器对应的 `QUALITY_BRIDGE_KEYS` 项必须明确配置 `directory_origins`（仅允许指定源站）和 `directory_user_id`（仅允许指定已映射服务身份）；`secret`、`audience` 由部署方安全注入。不得将真实签名密钥写入源码、说明、聊天或测试记录。

V2签名仅用于 `GET /api/admin/users`，固定100条/页、最多40页。主机/源站验证、重定向禁用、1MB响应边界沿用现有远端接口客户端。签名不用于创建账号、授权或其他远端操作。

UI入口：测试 → 平台集成 → 服务器连接配置 → 原45100账号服务 → 账号迁移预检。
