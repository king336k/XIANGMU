# 原生测试与缺陷管理实施计划

1. 先建立行为/权限/快照/回归门禁的 API 回归 RED；复用生产运行时依赖在专用测试容器及 test 数据库运行。
2. 用例 CRUD（新增版本而非覆盖）→固定版本计划→追加执行，各段运行 focused tests。
3. 失败提缺陷、独立缺陷状态、修复任务关系与回归关闭约束，测试跨项目和幂等。
4. 中文页面与项目导航，接真实 API，编译与类型检查。
5. 备份本地演示库，部署新增模型和前端，浏览器走完整闭环。
6. 运行完整后端测试、变更文件检查，记录证据与已知限制。

风险：两边不同权限、历史结果被重写、重复缺陷、未验证即关闭；通过同项目校验、不可变版本、事务锁与幂等、回归门禁验证。前端沿用现有 20 包 workspace，无升级。
