# 中文项目与测试管理：首版规格

用户于 2026-11-06 明确批准以 Plane 为底座、借鉴禅道流程的单系统原生开发，并要求执行。替代旧的两后端整合草案。

最终产品定位：新版45100，全新改版；45100所有现有业务功能将在此底座重新实现，不限于登录和交互嵌入。当前先完成底座与改版方案，后续按旧平台逐项盘点、实现和验收；底座首版不是最终改版交付。

## 目标与模块

- project-core：复用工作区、项目、成员、任务、迭代、文档。
- test-cases：项目内用例库、模块、前置条件、步骤与预期；需求关联；版本修改追加新版本。
- test-plans：命名计划，记录被测版本、环境、执行人，固定选择时的用例版本。
- test-execution：通过/失败/阻塞/跳过，实际结果、逐步结果、证据备注，重跑追加历史。
- defects：失败一键提缺陷，严重程度/重现与实际结果/影响版本/修复版本，关联 Plane 修复任务；待处理→处理中→已修复→已关闭，允许重开。
- reports：按计划条目的最新执行统计，执行率与通过率明确分母，保留历史和需求关联。
  依赖：project-core → test-cases → test-plans → test-execution → defects → reports。

## 数据与权限

使用 Plane Django/PostgreSQL 新增 quality 应用，复用原有用户与项目。所有路径 project+workspace 绑定；活跃项目成员及活跃工作区成员才可读，角色>=15 可写，guest 只读。关联需求、修复任务、用例与执行必须同项目。匿名无访问权限。
历史版本/执行不提供改写删除接口。变更用例使用 expected_version 防止覆盖。执行提交和失败提缺陷具备幂等语义；重复 ID 不同内容返回冲突。
修复任务完成不自动关闭缺陷。关闭必须指定在本次修复后产生的同源用例通过执行；旧结果、其他项目结果、其他用例结果不能关闭。

## 界面

沿用 Plane 主题、控件和项目布局，新增测试及缺陷入口；测试页含用例库/测试计划/执行记录/质量报告。表单和错误、空状态中文，有可见标签、键盘操作、加载及失败重试。无新 UI 依赖。

## 构建与验证

前端：pnpm --filter web check:types；pnpm --filter web build；pnpm exec oxlint <changed tsx/ts>；pnpm exec oxfmt --check <changed files>。
后端：pytest plane/tests/contract/app/test_quality.py；pytest plane/tests；python manage.py check；python manage.py makemigrations --check --dry-run。运行于独立测试数据库，禁止用正式演示库运行测试清理。
浏览器：在本地中文页面创建用例→计划→失败执行→提缺陷→关联任务→标记修复→通过回归→关闭；另验证用例更新不改变计划快照。

## 边界与交付

保留 AGPL 和原项目版权；借鉴流程，不复制商业版代码。不改现有工作区数据；迁移前 pg_dump。新增本地代码和构建镜像，其他业务容器不变。第一版为手工测试闭环，CI 自动化、Excel、跨产品共享库与细粒度测试角色后续再做。证据首版为文本记录和链接，二进制附件存储沿用现有任务能力，暂不承诺新测试附件上传。
