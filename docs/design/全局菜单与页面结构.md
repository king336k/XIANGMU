# 全局菜单与页面结构

2026-11-10，合并本轮页面截图与连续反馈。当前主实例为168版；169人员管理合并和170需求／任务分离正在实现、测试，本文是统一实施与验收清单，不将计划写成已交付。

## 一级入口

左侧全局导航默认按以下顺序：

1. 首页：个人待办、最近项目和常用链接。
2. 我的工作：本人负责、参与和待处理的工作。
3. 项目列表：选择项目、查看项目状态。
4. 工作总览：跨项目查看需求与任务，保留类型及其他筛选。
5. 统计报表：统计、分页明细与准确记录跳转。
6. 我的草稿、便笺：个人未提交内容和随手记录。
7. 项目归档：历史项目，位于低频区域。

设置统一从右上角头像进入。个人资料、密码和个人偏好保留独立名称，避免同一个“设置”按钮打开完全不同的页面。用户自定义导航的个人顺序不应被无提示重置。

## 项目导航

每个项目的默认二级业务入口：**需求 → 任务 → 缺陷 → 测试 → 版本迭代 → 文档与知识**。

| 模块 | 页面内容与操作 | 合并与区分规则 |
| --- | --- | --- |
| 需求 | 需求内容、验收标准、审批、变更及关联任务 | 独立需求入口，菜单和页标题都叫“需求” |
| 任务 | 研发任务的列表、看板及其他展示 | 默认排除正式需求，服务端列表、计数、分组、分页采用相同范围 |
| 缺陷 | 上报、材料、诊断、指派、方案、修复和回归 | 处理按钮随记录状态和岗位显示，不移到设置 |
| 测试 | 用例、用例集、计划、执行记录、测试资源和报告 | 测试员负责完整测试业务；最终确认和项目发布仍按角色核验 |
| 版本迭代 | 版本计划、阶段、进度、里程碑和发布验收 | 发布验收复用原业务接口，避免测试、版本两处重复配置 |
| 文档与知识 | 项目文档、知识库、知识问答和知识管理 | 协作文档与已审核知识区分，不因改名自动发布 |

迭代周期、功能模块、任务视图等可选功能保留，依现有功能开关显示；不将所有子功能同时展开到左侧。正式需求编号、任务编号、关联和历史记录不迁移、不重建。

## 一个设置入口、一套人员管理

设置中保留不同职责的栏目，统一壳、项目选择与导航：

| 栏目 | 主要内容 |
| --- | --- |
| 成员与权限 | 一张人员表、一个添加入口、一个编辑权限入口 |
| 来源关联 | 项目与数据平台项目、来源身份及目录关联 |
| 平台连接 | 全平台服务连接及凭据，由管理员管理 |
| 模型配置 | 平台模型连接与内置检索状态，由管理员管理 |
| 其他项目配置 | 状态、标签、功能开关、默认负责人等，按现有权限显示 |

人员表按账号ID合并已有信息，显示姓名、账号来源、岗位、项目访问状态和管理员标识。选择项目、搜索和分页不丢已选人员。工作空间访问范围和项目业务岗位是不同的数据，放在一个编辑入口中清楚区分，不能把访问级别包装成第六种业务角色。

“编辑权限”集中提供业务岗位多选、访问范围及管理员身份；不同后端接口的保存分别明确反馈，不能在部分成功时提示全部成功。改岗撤销旧岗位的独有权限，兼任取岗位能力并集，再登录保持当前设置。管理员拥有全部岗位能力，不要求兼任或第二名管理员审核本人事项。

“添加成员”可以选择已有账号、关联来源目录人员，或由有权限的管理员新建本地账号。新建和加入项目若分步骤执行，应明确当前完成阶段与重试方式，不能重复建号。来源账号仍由原平台维护密码。

邀请、移出、只读访问、项目负责人、默认负责人和必要高级配置必须仍可到达，不能因合并页面而删失。原来的三张常驻成员／账号／岗位表不直接纵向叠加。

## 唯一可见入口与历史链接

所有新菜单、按钮和快捷链接指向同一功能的新地址。工作空间、项目和个人安全页不再嵌入重复的全平台账号管理。

历史收藏和通知内的旧地址仅兼容跳转，不保留为第二套页面；项目、搜索、页码和页内定位需保留。业务详情里的“去设置”可以作为快捷跳转，但不能另开一份配置表单。

消息列表与个人通知偏好、各模块的归档／回收站、不同业务的导入导出不是同一功能，不为减少入口盲目合并。

## 名称、图标和页面显示

侧栏、页标题、面包屑、按钮和帮助说明采用同一业务名称。不使用“需求”菜单进入“需求管理”页面等不一致叫法；任务页不同时称“工作项”“研发事项”“需求与任务”。跨项目综合页面用“工作总览”。

默认图标：工作空间为楼宇、项目为文件夹、任务为清单；用户自定义图标和上传图片保持。页面需完整处理加载、空列表、错误、无权限、部分保存失败和成功反馈；手机与窄屏不挤出主要操作。

## 验收

- 一个人员修改界面完成数采员改测试员、项目经理改测试员、经理兼测试员；同会话立即生效，退出重登仍保留。
- 撤销经理后不能残留知识审核、角色管理等经理独有权限；管理员本人办理和自审留实际账号记录。
- 混合需求与任务样本下，项目任务页排除需求；工作总览仍可查看两类；各布局、计数、分组、分页一致。
- 新入口唯一，旧链接跳转保留项目、查询和定位；原有必要功能可到达。
- 按管理员、项目经理、技术员、测试员、数采员验证可见按钮和实际接口，不能只靠隐藏按钮鉴权。
- 运行代码、构建文件与交付包摘要一致；升级保留数据库、附件、配置、知识和操作历史。
